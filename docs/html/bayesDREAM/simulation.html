228    """
229    Simulate trans observations from fitted trans summary parameters.
230
231    The generative model is distribution-specific (see module docstring).
232    Parameterization (direct vs fold-change) is detected from the columns present
233    in ``trans_summary_df``.
234
235    Parameters
236    ----------
237    trans_summary_df : pd.DataFrame
238        One row per feature (gene / junction / etc.).  Required columns:
239
240        **Always required**
241
242        - ``feature``: feature name.
243        - ``function_type``: one of ``'single_hill'``, ``'additive_hill'``,
244          ``'polynomial'``.
245        - ``distribution`` *(optional)*: one of ``'negbinom'``, ``'normal'``,
246          ``'studentt'``, ``'binomial'``.  Defaults to ``'negbinom'`` when absent.
247
248        **Dispersion / noise (required by some distributions)**
249
250        - negbinom: ``phi_y_median`` or ``o_y_median`` (phi = 1/o^2).
251        - normal/studentt: ``o_y_median`` (used as sigma).
252        - studentt: also uses ``nu_y_median`` if present, else ``nu_y_default``.
253        - binomial: no dispersion column needed.
254
255        **Parameterization detection** (``y_ntc_median`` takes priority):
256
257        *Direct* — when ``A_median`` is a column.
258        *Fold-change* — when ``y_ntc_median`` is a column.  Only for negbinom.
259
260        Hill / polynomial parameter columns follow the same conventions as
261        ``save_trans_summary`` output.  See existing docstring (inline below)
262        for the full column listing by function_type and parameterization.
263
264        **Technical group effects** *(optional)*
265
266        - ``group_{g}_alpha_y_median`` or ``group_{g}_alpha_y_mean``: per-group
267          corrections (median preferred).  Interpretation is distribution-specific.
268
269    meta : pd.DataFrame
270        Cell metadata.  Required columns: ``cell``, ``guide``, ``target``.
271        When group columns are present in ``trans_summary_df``, must also contain
272        ``group_col``.
273    x_true : array-like, shape (n_cells,)
274        Per-cell x_true values (cis gene expression), aligned to ``meta`` rows.
275    x_counts : array-like, shape (n_cells,)
276        Per-cell raw cis gene counts, included unchanged as the cis gene row
277        in the output matrix.
278    cis_gene : str
279        Name of the cis gene (added as a row in the output count matrix).
280    sim_sum_factor : array-like or float, optional
281        Per-cell sum factors (default: 1.0).  **Only applied for negbinom.**
282        For simulated data to align with ``plot_xy_data``, pass the same sum
283        factor column used during ``fit_trans``::
284
285            sim_sum_factor = model.get_modality(model.primary_modality).sum_factors[col].values
286
287        This is NOT the sum factor for downstream fitting.
288    sim_denominator : array-like or float, optional
289        **Required for binomial.**  Total-count denominator per cell (and optionally
290        per feature).  Shapes accepted:
291
292        - scalar: same denominator for every cell and feature.
293        - 1-D array ``(n_cells,)``: per-cell denominator, shared across features.
294        - 2-D array ``(n_features, n_cells)``: independent per feature and cell.
295
296        For splice-junction data, ``sim_denominator`` is typically the per-cell
297        gene expression for the junction's gene.
298    sim_total_counts : array-like or float, optional
299        **Required for multinomial.**  Total read count per cell (and optionally per
300        feature) from which to draw the multinomial sample.  Shapes accepted:
301
302        - scalar: same total count for every cell and feature.
303        - 1-D array ``(n_cells,)``: per-cell total, shared across features.
304        - 2-D array ``(n_features, n_cells)``: independent per feature and cell.
305
306        Typically set to the observed total counts per donor/acceptor site per cell
307        (i.e. the sum of all category counts).
308    genes : list of str, optional
309        Subset of features to simulate.  Default: all in ``trans_summary_df``.

312        ``'technical_group_code'``).
313    seed : int, optional
314        Random seed for reproducibility.
315    fdr_threshold : float or None, optional

317        above this FDR are treated as absent.  Set to ``None`` to use raw
318        posterior means for all components.
319    nu_y_default : float, optional
320        Degrees of freedom for Student-t when ``nu_y_median`` is not in
321        ``trans_summary_df`` (default: 5.0).

323    Returns
324    -------
325    counts_df : pd.DataFrame or dict
326        For ``negbinom``, ``normal``, ``studentt``, ``binomial``: a DataFrame

328        counts; normal/studentt → continuous floats.  Always includes the cis gene
329        as an extra row with raw ``x_counts``.
330
331        For ``multinomial``: a dict with keys:
332

704
705            # ---- Clamp K-1 probabilities and compute residual ----
706            y_pred_cats = np.clip(y_pred_cats, 1e-6, 1.0 - 1e-6)
707            sum_kminus1 = y_pred_cats.sum(axis=-1, keepdims=True)  # (n_genes, n_cells, 1)
708            over = sum_kminus1 > (1.0 - 1e-6)
709            y_pred_cats = np.where(over, y_pred_cats * (1.0 - 1e-6) / sum_kminus1, y_pred_cats)
710            sum_kminus1 = y_pred_cats.sum(axis=-1, keepdims=True)
711            y_K_col = np.clip(1.0 - sum_kminus1, 1e-6, 1.0)
712            probs_3d = np.concatenate([y_pred_cats, y_K_col], axis=-1)  # (n_genes, n_cells, K_max)
713
714            # ---- Apply technical effects (log-additive per category, then softmax) ----
715            # alpha_y for multinomial is [C, T, K]: each category has its own group offset.
716            mn_alpha_y = _get_multinomial_alpha_y(df, K_max_mn)
717            if mn_alpha_y is not None and group_col in meta.columns:
718                groups = meta[group_col].values.astype(int)
719                alpha_y_per_cell = mn_alpha_y[:, groups, :]  # (n_genes, n_cells, K_max)
720                log_probs = np.log(np.maximum(probs_3d, 1e-10))
721                log_probs = log_probs + alpha_y_per_cell      # (n_genes, n_cells, K_max)
722                log_probs -= log_probs.max(axis=-1, keepdims=True)
723                probs_3d = np.exp(log_probs)
724                probs_3d /= probs_3d.sum(axis=-1, keepdims=True)
725
726            # ---- Sample ----
727            y_obs_3d = np.zeros((n_genes, n_cells, K_max_mn), dtype=int)
728            for t in range(n_genes):
729                for n_idx in range(n_cells):
730                    n_total = total_counts_arr[t, n_idx]
731                    if n_total <= 0:
732                        continue
733                    p = probs_3d[t, n_idx, :]
734                    p_sum = p.sum()
735                    if p_sum <= 0 or not np.isfinite(p_sum):
736                        continue
737                    y_obs_3d[t, n_idx, :] = rng.multinomial(n=int(n_total), pvals=p / p_sum)
738
739            # ---- Build output dict (use add_custom_modality to re-ingest) ----
740            cells = (meta['cell'].values if 'cell' in meta.columns
741                     else [f'cell_{i}' for i in range(n_cells)])
742            return {
743                'counts': y_obs_3d,                    # (n_features, n_cells, K_max)
744                'feature_names': list(gene_names),
745                'feature_meta': df.reset_index(drop=True),
746                'cells': list(cells),
747                'cis_gene': cis_gene,
748                'cis_counts': x_counts,
749                'K_max': K_max_mn,
750            }
751
752        A = df['A_median'].values
753
754        if function_type == 'additive_hill':
755            for col in ['Vmax_a_median', 'K_a_median', 'n_a_median',
756                         'Vmax_b_median', 'K_b_median', 'n_b_median']:
757                if col not in df.columns:
758                    raise ValueError(f"Missing required column for additive_hill: {col}")
759
760            Vmax_a = df['Vmax_a_median'].values
761            K_a = df['K_a_median'].values
762            n_a = df['n_a_median'].values
763            alpha = df['alpha_median'].values.copy() if 'alpha_median' in df.columns else np.ones(n_genes)
764            Vmax_b = df['Vmax_b_median'].values
765            K_b = df['K_b_median'].values
766            n_b = df['n_b_median'].values
767            beta = df['beta_median'].values.copy() if 'beta_median' in df.columns else np.ones(n_genes)
768
769            if fdr_threshold is not None:
770                if 'fdr_alpha' in df.columns:
771                    fdr_a = df['fdr_alpha'].values
772                    alpha = np.where(np.isfinite(fdr_a) & (fdr_a <= fdr_threshold), alpha, 0.0)
773                if 'fdr_beta' in df.columns:
774                    fdr_b = df['fdr_beta'].values
775                    beta = np.where(np.isfinite(fdr_b) & (fdr_b <= fdr_threshold), beta, 0.0)
776
777            hill_a = _hill(x_exp, Vmax_a[:, np.newaxis], K_a[:, np.newaxis], n_a[:, np.newaxis])
778            hill_b = _hill(x_exp, Vmax_b[:, np.newaxis], K_b[:, np.newaxis], n_b[:, np.newaxis])
779
780            y_pred = (A[:, np.newaxis]
781                      + alpha[:, np.newaxis] * hill_a
782                      + beta[:, np.newaxis] * hill_b)
783
784        elif function_type == 'single_hill':
785            for col in ['Vmax_a_median', 'K_a_median', 'n_a_median']:
786                if col not in df.columns:
787                    raise ValueError(f"Missing required column for single_hill: {col}")
788
789            Vmax_a = df['Vmax_a_median'].values
790            K_a = df['K_a_median'].values
791            n_a = df['n_a_median'].values
792            alpha = df['alpha_median'].values.copy() if 'alpha_median' in df.columns else np.ones(n_genes)
793
794            if fdr_threshold is not None and 'fdr_alpha' in df.columns:
795                fdr_a = df['fdr_alpha'].values
796                alpha = np.where(np.isfinite(fdr_a) & (fdr_a <= fdr_threshold), alpha, 0.0)
797
798            hill_a = _hill(x_exp, Vmax_a[:, np.newaxis], K_a[:, np.newaxis], n_a[:, np.newaxis])
799            y_pred = A[:, np.newaxis] + alpha[:, np.newaxis] * hill_a
800
801        elif function_type == 'polynomial':
802            coef_cols = sorted(
803                [c for c in df.columns if c.startswith('coef_') and c.endswith('_median')],
804                key=lambda c: int(c.split('_')[1])
805            )
806            if not coef_cols:
807                raise ValueError("No polynomial coefficient columns found (coef_N_median).")
808
809            if distribution == 'negbinom':
810                # Polynomial operates in log2(x) space: log2(y) = sum(coef_i * log2(x)^i)
811                # where coef_0 = log2(A) and coef_1..d are the polynomial terms.
812                log2_x_exp = np.log2(np.maximum(x_exp, 1e-12))
813                log2_y_pred = np.zeros((n_genes, n_cells))
814                for i, col in enumerate(coef_cols):
815                    log2_y_pred += df[col].values[:, np.newaxis] * np.power(log2_x_exp, i)
816                y_pred = np.power(2.0, log2_y_pred)
817
818            elif distribution in ('normal', 'studentt'):
819                # Polynomial in linear x space: y = sum(coef_i * x^i)
820                # where coef_0 = A
821                y_pred = np.zeros((n_genes, n_cells))
822                for i, col in enumerate(coef_cols):
823                    y_pred += df[col].values[:, np.newaxis] * np.power(x_exp, i)
824
825            elif distribution == 'binomial':
826                # Polynomial in linear x space on logit scale:
827                # logit(p) = sum(coef_i * x^i) where coef_0 = logit(A)
828                logit_p = np.zeros((n_genes, n_cells))
829                for i, col in enumerate(coef_cols):
830                    logit_p += df[col].values[:, np.newaxis] * np.power(x_exp, i)
831                y_pred = 1.0 / (1.0 + np.exp(-logit_p))  # sigmoid
832
833            else:
834                raise ValueError(f"Unsupported distribution for polynomial: {distribution}")
835
836        else:
837            raise ValueError(f"Unsupported function_type: {function_type}")
838
839    # ------------------------------------------------------------------ #
840    # Apply technical effects and (for negbinom) sum factors               #
841    # ------------------------------------------------------------------ #
842    # Floor y_pred to avoid log(0) in negbinom / logit(0) in binomial
843    if distribution == 'negbinom':
844        y_pred = np.maximum(y_pred, 1e-6)
845    elif distribution == 'binomial':
846        # Already a probability; clamp before logit in technical-effects step
847        y_pred = np.clip(y_pred, 1e-6, 1.0 - 1e-6)
848
849    alpha_y_cols = _get_alpha_y_cols(df)
850
851    mu_or_logit = _apply_technical_effects_and_scale(
852        distribution, y_pred, alpha_y_cols, df, meta, group_col, sum_factors,
853        n_genes, n_cells
854    )
855
856    # ------------------------------------------------------------------ #
857    # Sample                                                                #
858    # ------------------------------------------------------------------ #
859
860    if distribution == 'negbinom':
861        phi_y_exp = phi_y[:, np.newaxis]                      # (n_genes, 1)
862        prob = phi_y_exp / (phi_y_exp + mu_or_logit)          # (n_genes, n_cells)
863        prob = np.clip(prob, 1e-10, 1 - 1e-10)
864        y_obs = rng.negative_binomial(n=phi_y_exp, p=prob)    # (n_genes, n_cells)
865
866    elif distribution == 'normal':
867        sigma_y_exp = sigma_y[:, np.newaxis]                  # (n_genes, 1)
868        y_obs = rng.normal(loc=mu_or_logit, scale=sigma_y_exp)
869
870    elif distribution == 'studentt':
871        # scipy.stats.t is used because numpy has no native Student-t RNG
872        from scipy.stats import t as scipy_t
873        sigma_y_exp = sigma_y[:, np.newaxis]                  # (n_genes, 1)
874        nu_y_exp = nu_y[:, np.newaxis]                        # (n_genes, 1)
875        y_obs = scipy_t.rvs(df=nu_y_exp, loc=mu_or_logit, scale=sigma_y_exp,
876                             random_state=rng)
877        y_obs = np.reshape(y_obs, (n_genes, n_cells))  # scipy may squeeze n_genes=1
878
879    elif distribution == 'binomial':
880        # mu_or_logit holds logit(p); convert to probability
881        prob = 1.0 / (1.0 + np.exp(-mu_or_logit))
882        prob = np.clip(prob, 1e-10, 1 - 1e-10)
883        y_obs = rng.binomial(n=denom_arr, p=prob)             # (n_genes, n_cells)
884
885    # ------------------------------------------------------------------ #
886    # Build output DataFrame                                                #
887    # ------------------------------------------------------------------ #
888    cells = meta['cell'].values if 'cell' in meta.columns else [f'cell_{i}' for i in range(n_cells)]
889
890    counts_dict = {}
891    for i, gene in enumerate(gene_names):
892        counts_dict[gene] = y_obs[i, :]
893    counts_dict[cis_gene] = x_counts.astype(int)
894
895    counts_df = pd.DataFrame(counts_dict, index=cells).T
896    counts_df.index.name = None
897
898    return counts_df

Simulate trans observations from fitted trans summary parameters.

The generative model is distribution-specific (see module docstring). Parameterization (direct vs fold-change) is detected from the columns present in trans_summary_df.

Parameters

  • trans_summary_df (pd.DataFrame): One row per feature (gene / junction / etc.). Required columns:

    Always required

    • feature: feature name.
    • function_type: one of 'single_hill', 'additive_hill', 'polynomial'.
    • distribution (optional): one of 'negbinom', 'normal', 'studentt', 'binomial'. Defaults to 'negbinom' when absent.

    Dispersion / noise (required by some distributions)

    • negbinom: phi_y_median or o_y_median (phi = 1/o^2).
    • normal/studentt: o_y_median (used as sigma).
    • studentt: also uses nu_y_median if present, else nu_y_default.
    • binomial: no dispersion column needed.

    Parameterization detection (y_ntc_median takes priority):

    Direct — when A_median is a column. Fold-change — when y_ntc_median is a column. Only for negbinom.

    Hill / polynomial parameter columns follow the same conventions as save_trans_summary output. See existing docstring (inline below) for the full column listing by function_type and parameterization.

    Technical group effects (optional)

    • group_{g}_alpha_y_median or group_{g}_alpha_y_mean: per-group corrections (median preferred). Interpretation is distribution-specific.
  • meta (pd.DataFrame): Cell metadata. Required columns: cell, guide, target. When group columns are present in trans_summary_df, must also contain group_col.
  • x_true (array-like, shape (n_cells,)): Per-cell x_true values (cis gene expression), aligned to meta rows.
  • x_counts (array-like, shape (n_cells,)): Per-cell raw cis gene counts, included unchanged as the cis gene row in the output matrix.
  • cis_gene (str): Name of the cis gene (added as a row in the output count matrix).

  • sim_sum_factor (array-like or float, optional): Per-cell sum factors (default: 1.0). Only applied for negbinom. For simulated data to align with plot_xy_data, pass the same sum factor column used during fit_trans::

    sim_sum_factor = model.get_modality(model.primary_modality).sum_factors[col].values

    This is NOT the sum factor for downstream fitting.

  • sim_denominator (array-like or float, optional): Required for binomial. Total-count denominator per cell (and optionally per feature). Shapes accepted:

    • scalar: same denominator for every cell and feature.
    • 1-D array (n_cells,): per-cell denominator, shared across features.
    • 2-D array (n_features, n_cells): independent per feature and cell.

    For splice-junction data, sim_denominator is typically the per-cell gene expression for the junction's gene.

  • sim_total_counts (array-like or float, optional): Required for multinomial. Total read count per cell (and optionally per feature) from which to draw the multinomial sample. Shapes accepted:

    • scalar: same total count for every cell and feature.
    • 1-D array (n_cells,): per-cell total, shared across features.
    • 2-D array (n_features, n_cells): independent per feature and cell.

    Typically set to the observed total counts per donor/acceptor site per cell (i.e. the sum of all category counts).

  • genes (list of str, optional): Subset of features to simulate. Default: all in trans_summary_df.
  • group_col (str, optional): Column in meta with integer technical group codes (default: 'technical_group_code').
  • seed (int, optional): Random seed for reproducibility.
  • fdr_threshold (float or None, optional): FDR threshold for gating Hill components (default: 0.05). Components above this FDR are treated as absent. Set to None to use raw posterior means for all components.
  • nu_y_default (float, optional): Degrees of freedom for Student-t when nu_y_median is not in trans_summary_df (default: 5.0).
Returns

  • counts_df (pd.DataFrame or dict): For negbinom, normal, studentt, binomial: a DataFrame with features as rows and cells as columns. negbinom/binomial → integer counts; normal/studentt → continuous floats. Always includes the cis gene as an extra row with raw x_counts.

    For multinomial: a dict with keys:

    • 'counts': np.ndarray of shape (n_features, n_cells, K_max), integer category counts.
    • 'feature_names': list of feature names.
    • 'feature_meta': pd.DataFrame with per-feature metadata (same rows as trans_summary_df after any gene subsetting).
    • 'cells': list of cell names.
    • 'cis_gene': the cis gene name.
    • 'cis_counts': np.ndarray of raw per-cell cis counts.
    • 'K_max': int, total number of categories including the residual.

 37def permute_from_ntc(
 38    modality,
 39    meta: pd.DataFrame,
 40    features2permute: Optional[Union[list, str]] = 'All',
 41    covariates: Optional[list] = None,
 42    sum_factor_col: str = 'sum_factor_adj',
 43    seed: Optional[int] = None,
 44) -> None:
 45    """
 46    Permute NTC expression into perturbed cells in-place.
 47
 48    For each feature in ``features2permute``, within each covariate group,
 49    samples the NTC expression distribution (with replacement) and assigns
 50    those values to perturbed (non-NTC) cells.  The sampling strategy is
 51    distribution-aware — see module docstring for details.
 52
 53    Parameters
 54    ----------
 55    modality : Modality
 56        The modality whose counts will be permuted.  Modified in-place.
 57    meta : pd.DataFrame
 58        Cell metadata.  Required columns: ``'cell'``, ``'target'``
 59        (NTC cells have ``target == 'ntc'``).
 60    features2permute : list of str/int, ``'All'``, or ``None``
 61        Feature names (or integer indices) to permute.  ``'All'`` / ``None``
 62        permutes every feature in the modality.
 63    covariates : list of str, optional
 64        Columns in ``meta`` used to stratify permutation.  Permutation is
 65        performed independently within each unique combination of covariate
 66        values so that each group's NTC distribution is preserved separately.
 67        If ``None``, all cells are treated as one group.
 68    sum_factor_col : str, default ``'sum_factor_adj'``
 69        Column in ``modality.sum_factors`` used to normalise counts for
 70        ``negbinom`` permutation.  Ignored for other distributions.
 71    seed : int, optional
 72        Random seed for reproducibility.
 73    """
 74    rng = np.random.default_rng(seed)
 75    dist = modality.distribution
 76
 77    # ------------------------------------------------------------------ #
 78    # Resolve feature list                                                  #
 79    # ------------------------------------------------------------------ #
 80    feature_names = modality.feature_names
 81    n_features = modality.dims['n_features']
 82
 83    if features2permute is None or features2permute == 'All' or features2permute == ['All']:
 84        feat_indices = list(range(n_features))
 85    else:
 86        if isinstance(features2permute, str):
 87            features2permute = [features2permute]
 88        if feature_names is not None:
 89            name_to_idx = {n: i for i, n in enumerate(feature_names)}
 90            feat_indices = []
 91            for f in features2permute:
 92                if isinstance(f, str) and f in name_to_idx:
 93                    feat_indices.append(name_to_idx[f])
 94                elif isinstance(f, int) and f < n_features:
 95                    feat_indices.append(f)
 96        else:
 97            feat_indices = [f for f in features2permute if isinstance(f, int) and f < n_features]
 98
 99    if not feat_indices:
100        return
101
102    # ------------------------------------------------------------------ #
103    # Validate distribution-specific prerequisites                          #
104    # ------------------------------------------------------------------ #
105    if dist == 'negbinom':
106        if modality.sum_factors is None or sum_factor_col not in modality.sum_factors.columns:
107            raise ValueError(
108                f"No column '{sum_factor_col}' in modality.sum_factors. "
109                "Run adjust_ntc_sum_factor() first."
110            )
111
112    if dist == 'binomial' and modality.denominator is None:
113        raise ValueError(
114            "modality.denominator is required for binomial permutation."
115        )
116
117    if dist == 'multinomial' and modality.counts.ndim != 3:
118        raise ValueError(
119            "multinomial permutation requires 3-D counts (n_features, n_cells, n_categories)."
120        )
121
122    # ------------------------------------------------------------------ #
123    # Build cell → column index mapping                                    #
124    # ------------------------------------------------------------------ #
125    cell_names = modality.cell_names
126    if cell_names is None:
127        raise ValueError("modality.cell_names must be set for permutation.")
128    cell_to_idx = {c: i for i, c in enumerate(cell_names)}
129
130    # ------------------------------------------------------------------ #
131    # Work on a copy of counts (write back at the end)                     #
132    # ------------------------------------------------------------------ #
133    is_sparse_2d = sparse.issparse(modality.counts)
134
135    if dist == 'multinomial':
136        counts_work = np.array(modality.counts, dtype=float)   # (T, C, K)
137    elif is_sparse_2d:
138        counts_work = modality.counts.copy()
139    else:
140        counts_work = np.array(modality.counts, dtype=float)   # (T, C)
141
142    # Denominator copy for binomial
143    if dist == 'binomial':
144        if sparse.issparse(modality.denominator):
145            denom_arr = modality.denominator.toarray().astype(float)
146        else:
147            denom_arr = np.array(modality.denominator, dtype=float)   # (T, C)
148
149    # ------------------------------------------------------------------ #
150    # Covariate-stratified permutation                                     #
151    # ------------------------------------------------------------------ #
152    groups = meta.groupby(covariates) if covariates else [(None, meta)]
153
154    for _key, group in groups:
155        pert_cells = group.loc[group['target'] != 'ntc', 'cell'].values
156        ntc_cells  = group.loc[group['target'] == 'ntc',  'cell'].values
157
158        if len(pert_cells) == 0 or len(ntc_cells) == 0:
159            continue
160
161        pert_idx = [cell_to_idx[c] for c in pert_cells if c in cell_to_idx]
162        ntc_idx  = [cell_to_idx[c] for c in ntc_cells  if c in cell_to_idx]
163
164        if not pert_idx or not ntc_idx:
165            continue
166
167        # ---- negbinom ------------------------------------------------- #
168        if dist == 'negbinom':
169            sf_ntc  = modality.sum_factors.loc[ntc_cells,  sum_factor_col].values
170            sf_pert = modality.sum_factors.loc[pert_cells, sum_factor_col].values
171
172            for feat_row in feat_indices:
173                if is_sparse_2d:
174                    ntc_counts = np.asarray(
175                        counts_work[feat_row, ntc_idx].todense()
176                    ).flatten().astype(float)
177                else:
178                    ntc_counts = counts_work[feat_row, ntc_idx]
179
180                rates = ntc_counts / np.maximum(sf_ntc, 1e-12)
181                sampled_rates = rng.choice(rates, size=len(pert_idx), replace=True)
182                new_counts = np.round(sampled_rates * sf_pert)
183
184                if is_sparse_2d:
185                    counts_work = counts_work.tolil()
186                    for i, col in enumerate(pert_idx):
187                        counts_work[feat_row, col] = new_counts[i]
188                    counts_work = counts_work.tocsr()
189                else:
190                    counts_work[feat_row, pert_idx] = new_counts
191
192        # ---- binomial ------------------------------------------------- #
193        elif dist == 'binomial':
194            for feat_row in feat_indices:
195                ntc_counts = counts_work[feat_row, ntc_idx]
196                ntc_denom  = denom_arr[feat_row, ntc_idx]
197
198                fracs = ntc_counts / np.maximum(ntc_denom, 1e-12)
199                sampled_fracs = rng.choice(fracs, size=len(pert_idx), replace=True)
200                pert_denom = denom_arr[feat_row, pert_idx]
201                new_counts = np.round(sampled_fracs * pert_denom)
202
203                counts_work[feat_row, pert_idx] = new_counts
204
205        # ---- multinomial ---------------------------------------------- #
206        elif dist == 'multinomial':
207            for feat_row in feat_indices:
208                ntc_cat_counts = counts_work[feat_row, ntc_idx, :]    # (N_ntc, K)
209                ntc_totals = ntc_cat_counts.sum(axis=1)                # (N_ntc,)
210
211                with np.errstate(invalid='ignore', divide='ignore'):
212                    ntc_fracs = ntc_cat_counts / np.maximum(ntc_totals[:, np.newaxis], 1e-12)
213
214                sampled_row_idx = rng.integers(0, len(ntc_idx), size=len(pert_idx))
215                sampled_fracs = ntc_fracs[sampled_row_idx, :]          # (N_pert, K)
216
217                pert_totals = counts_work[feat_row, pert_idx, :].sum(axis=1)  # (N_pert,)
218                new_counts = np.round(
219                    sampled_fracs * np.maximum(pert_totals[:, np.newaxis], 0)
220                )
221
222                counts_work[feat_row, pert_idx, :] = new_counts
223
224        # ---- normal / studentt ---------------------------------------- #
225        elif dist in ('normal', 'studentt'):
226            for feat_row in feat_indices:
227                ntc_vals = counts_work[feat_row, ntc_idx]
228                sampled = rng.choice(ntc_vals, size=len(pert_idx), replace=True)
229                counts_work[feat_row, pert_idx] = sampled
230
231        else:
232            raise ValueError(
233                f"permute_from_ntc does not support distribution '{dist}'. "
234                "Supported: negbinom, binomial, multinomial, normal, studentt."
235            )
236
237    # ------------------------------------------------------------------ #
238    # Write back                                                           #
239    # ------------------------------------------------------------------ #
240    modality.counts = counts_work

  • modality (Modality): The modality whose counts will be permuted. Modified in-place.
  • meta (pd.DataFrame): Cell metadata. Required columns: 'cell', 'target' (NTC cells have target == 'ntc').
  • features2permute (list of str/int, 'All', or None): Feature names (or integer indices) to permute. 'All' / None permutes every feature in the modality.
  • covariates (list of str, optional): Columns in meta used to stratify permutation. Permutation is performed independently within each unique combination of covariate values so that each group's NTC distribution is preserved separately. If None, all cells are treated as one group.
  • sum_factor_col (str, default 'sum_factor_adj'): Column in modality.sum_factors used to normalise counts for negbinom permutation. Ignored for other distributions.
  • seed (int, optional): Random seed for reproducibility.
